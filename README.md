# Website_Sustainable_SmallProject
A multi-page website about everyday sustainability, built with HTML, CSS and JavaScript as a Year 1 coursework project at Dundalk Institute of Technology (DkIT), BSc (Hons) in Computing in Software Development.

## Live demo

https://garychew0717.github.io/Website_Sustainable_SmallProject/index.html

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| Electricity | `Electricity.html` |
| Water | `Water.html` |
| Recycling | `Recycling.html` |
| Image Gallery | `ImageGalery.html` |
| About | `About.html` |
| Contact | `Contact.html` |

## Tech stack

- **HTML5** for page structure
- **CSS3** with one shared stylesheet (`Commonstyle.css`) plus page-specific stylesheets
- **JavaScript** for the navigation menu (`menu.js`) and display mode (`mode.js`)
- **Git / GitHub** for version control

## Project structure

```
├── index.html
├── About.html / About.css
├── Contact.html / Contact.css
├── Electricity.html / Electricity.css
├── Water.html / Water.css
├── Recycling.html / Recyclingstyle.css
├── ImageGalery.html / ImageGalery.css
├── Commonstyle.css / Style.css
├── menu.js
├── mode.js
└── Image/
```

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/GaryChew0717/Website_Sustainable_SmallProject.git
   ```
2. Open `index.html` in any web browser. No installation or build step is needed.
